# ValoraEX Partner Logo Web Standard v1.0

## Master asset standard
- Master canvas: 1200 × 480 px
- PNG: transparent background
- WebP: transparent/lossless companion file
- Preserve original official logo proportions
- Centre horizontally and vertically
- Do not stretch, crop, recolour, redraw or add effects
- Balance logos by visual presence / height, not by forcing equal widths

## Recommended rolling-display implementation
Desktop:
- container width: approx. 240–260 px
- container height: approx. 90–100 px
- image max-height: 70–78 px
- image max-width: 85%
- width: auto; object-fit: contain

Mobile:
- container width: approx. 160–180 px
- container height: approx. 70–80 px
- image max-height: 50–60 px
- width: auto; object-fit: contain

## Interaction
- slow continuous horizontal movement
- seamless loop
- pause on hover where appropriate
- generous spacing
- original official colours
- no hierarchy, endorsement or exclusivity implied

## Future partner rule
Apply exactly the same 1200×480 transparent-master process to every newly approved partner/appreciation logo before adding it to the rolling display.
